## What I'm working on

- **University dashboard**: a personal dashboard with a calendar that imports `.ics` files, login, and an MCP server so an AI assistant can read my schedule. Built with React, Vite, Express, and MongoDB.
- **Math explainers**: interactive pages for concepts like the Fourier transform, Hilbert spaces, and the delta function. Each page has a visual you can drag, and the math updates next to it.
- **MCP client and servers**: a chat client and small Python MCP servers that wrap third-party APIs as tools.
- **jingyichai.com**: my personal site, with a back office and API.

## Projects

| Project | What it does |
| --- | --- |
| [crystal-simulation](https://github.com/yi-chai/crystal-simulation) | Python scripts and GROMACS setup for simulating the crystal structure of an organic small molecule: annealing, molecule insertion, structure-factor analysis, and plotting. |
| [crystal-reconstruct](https://github.com/yi-chai/crystal-reconstruct) | A two-stage GROMACS program that builds a crystal structure from a single molecule, then fills the gaps with more molecules. |
